# PlagIA v3 — homologação independente
Next.js / TypeScript. Execute npm install, npm test, npm run dev; abra /plagio. Esta fase calcula estatísticas documentais reais no navegador, sem transmitir manuscritos. Não mede similaridade externa ou plágio, não aceita pagamentos e não gera PDF. A versão Streamlit anterior permanece preservada. Antes de produção: banco Supabase independente, autenticação, processamento PDF/DOCX, fontes comparáveis, testes de segurança, PDF server-side e confirmação de PIX. O domínio protocolo.me deve encaminhar somente /plagio e /plagio/* ao novo projeto, após verificar o host atual. Não alterar DNS global.
